Data Privacy & Security Protocols

  • Secure Document Uploads:

    Filenames are sanitized via werkzeug.utils.secure_filename with random hex prefixes to prevent directory traversal.

  • Spreadsheet Injection Prevention:

    All CSV export values beginning with =, +, -, or @ are prepended with an apostrophe to prevent DDE code execution in Excel.

  • Password Cryptography:

    User credentials are encrypted using PBKDF2 with SHA-256 password hashing. Plaintext passwords are never stored.

  • Candidate Privacy Notice:

    Uploaded documents are retained in the local storage volume strictly for the duration of the screening review pipeline.
